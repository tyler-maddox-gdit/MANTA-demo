Plan

  • Conformance level: Section 508, WCAG 2.1 or 2.2 AA.
  • Criterion checklists: the Trusted Tester tests, as acceptance criteria.
  • Config in the repo: the pages, the rules, the fail floor.

Develop

  • Gate on localhost: new debt fails, legacy debt tolerated.
  • Source stamping: every finding names file and line.
  • AI fix patch: cluster, fix, git apply.

Integrate

  • Required check: the same gate on every pull request.
  • Suggested changes: the fixes on the diff, applied in one click.
  • Code scanning and nightly: SARIF alerts; a scan through the sign-in every night.

Test

  • Workbench: scan from the browser, no command line.
  • Verdicts outrank the scan: attest, add an issue, rescan.
  • Extended rules and focus order: keyboard, traps, states.

Release

  • ACR draft: into the ITI VPAT 2.5 template.
  • Exports: defects, report, workbook.
  • One run, append-only: evidence, verdicts, paperwork.

QA and release

Test and Release: the Workbench, and the paperwork that comes out of it.

  • Workbench. A scan launched from the browser: pages, level, add-ons, Start. The report reads by criterion. No command line.
  • Verdicts outrank the scan. Attest a criterion, add what no rule sees, rescan one issue against the live site. Every call is recorded on the run.
  • Extended rules and focus order. Keyboard traps, skip links, status messages, states; the Tab stops drawn on the page. Evidence for the judgment calls.
  • ACR draft and exports. The conformance report into the VPAT template, the defects export, the full report. From the same run, nothing retyped.

DevOps

Integrate: the gate on every pull request, and every night.

  • Required check. The developer's gate, now on GitHub's machines. While it is red, the change cannot merge.
  • Suggested changes. MANTA's fixes posted on the diff's own lines; one click applies them in one commit. The gate runs again and goes green.
  • Code scanning. The same findings as SARIF alerts, beside every other scanner. Tracked the same way.
  • Nightly. Through the sign-in to the pages no pull request touches, with the extended rules. The run QA opens next morning.

Development

Plan and Develop: the target agreed, and the developer's own gate.

  • Conformance level and checklists. Section 508, WCAG 2.1 or 2.2 AA, with the Trusted Tester tests per criterion. The acceptance criteria before any code.
  • Gate on localhost. A scan compared against the committed baseline: new debt fails, legacy debt is tolerated. The count only goes down.
  • Source stamping. Every finding names the file and line that wrote the element.
  • AI fix patch. Findings grouped by cause, one fix per cause, written to the source in the project's conventions. One command applies it.
